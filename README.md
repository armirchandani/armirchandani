### 3. Oracle Stock Movement Classification

An exploratory project applying K-Nearest Neighbors (KNN) to historical financial data.

| Area | Details |
| --- | --- |
| **Objective** | Explore how KNN classifies daily Oracle stock movements. |
| **Tools** | Python, Pandas, NumPy, yfinance, scikit-learn, Matplotlib |
| **Data** | **June 1986–December 2024**, with **5 input features:** Open, High, Low, Close, and Volume. |
| **Approach** | Calculated daily returns, standardized features using training data, and trained KNN with **5 neighbors** and a random **80/20 split**. |
| **Metrics — model performance** | Approximately **52% test accuracy** in the saved notebook output. |
| **Business analysis relevance** | Evaluating a financial analytics approach and explaining its limitations before using the results to support a decision. |

**Limitation:** Same-day inputs and a random split do not establish future forecasting performance. Next steps include lagged inputs and chronological evaluation.
